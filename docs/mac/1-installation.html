Installer le bot d'upload sur Mac

Une seule fois. Après, tu ne refais plus jamais ça.

👋 Ce guide t'explique, étape par étape, comment mettre en route le bot qui envoie automatiquement tes prods sur ta boutique Shopify — même s'il n'était fait que pour Windows au départ.

Prends ton temps. Fais les étapes dans l'ordre, une par une. Tu n'as pas besoin de comprendre le "pourquoi", juste de suivre.

⏱️ Ça prend environ 1h30 à 3h la première fois.
1

Vérifie que tu as Chrome

Ouvre le dossier Applications sur ton Mac. Si Google Chrome n'y est pas, télécharge-le ici :

🔗 À faire : google.com/chrome
2

Ouvre le Terminal

C'est une appli déjà installée sur ton Mac, avec un fond noir.

👉 Comment faire : appuie sur Cmd + Espace, tape Terminal, puis appuie sur Entrée.
3

Installe les outils de base

Copie cette ligne, colle-la dans le Terminal, puis appuie sur Entrée :

brew --version

Si un numéro de version s'affiche → passe direct à l'étape 4.
Si tu vois "command not found" → va sur brew.sh et suis leurs instructions, puis reviens ici.

4

Installe Python

Copie-colle cette ligne dans le Terminal, puis Entrée :

brew install python python-tk
⏳ Patiente : ça peut prendre 5 à 10 minutes. Beaucoup de texte défile, c'est normal.
5

Crée un compte Shopify pour le bot

C'est comme donner une clé au bot pour qu'il puisse parler à ta boutique.

  1. Va sur dev.shopify.com/dashboard
  2. Apps → Create app → Start from Dev Dashboard
  3. Nom : Beat Uploader
  4. App URL : https://shopify.dev/apps/default-app-home
  5. Allowed redirection URL(s) : https://localhost

Dans Scopes (pas "Optional scopes"), colle exactement ceci :

write_products,read_products,write_files,read_files,write_metaobject_definitions,read_metaobject_definitions,write_metaobjects,read_metaobjects,write_publications,read_publications

Puis clique Release → Home → Install app → choisis ta boutique → Install.

Retourne dans Settings : tu vois un Client ID et un Secret. Laisse cet onglet ouvert.

🔒 Important : le Secret, c'est comme un mot de passe. Ne le montre à personne, ne le colle nulle part sauf là où ce guide te le demande.
6

Télécharge le bot

Va sur cette page, clique sur le bouton vert Code, puis Download ZIP :

🔗 github.com/Oscarimov/BeatStars-Shopify-Distribution

Décompresse le fichier (double-clic dessus). Tu obtiens un dossier avec, à l'intérieur, un autre dossier appelé scripts.

7

Ajoute les fichiers spéciaux Mac

Dans le dossier fichiers_a_copier_dans_scripts qu'on t'a envoyé, il y a 4 fichiers. Mets-les dans le dossier scripts du bot (celui de l'étape 6).

✅ Résultat attendu : le dossier scripts contient maintenant, en plus des fichiers du bot, : setup.sh, login_shopify_chrome.sh, run_single_upload.sh et macos.patch.
8

Va dans le dossier avec le Terminal

Dans le Terminal, tape cd puis une espace (sans appuyer sur Entrée). Ensuite, glisse le dossier scripts depuis le Finder directement dans la fenêtre du Terminal. Le chemin s'écrit tout seul. Appuie sur Entrée.

✅ Tu sais que c'est bon quand la ligne se termine par scripts %
9

Applique le correctif Mac

Toujours dans le Terminal, colle cette ligne, puis Entrée :

cd .. git apply scripts/macos.patch cd scripts

Rien ne s'affiche si ça marche : c'est normal.

10

Installe le bot

Colle cette ligne, puis Entrée :

PATH="/opt/homebrew/bin:$PATH" bash setup.sh
⏳ Patiente quelques minutes. Attends de voir la ligne : "Installation terminée".
11

Donne ses infos au bot

Colle cette ligne, puis Entrée :

cp config.example.json config.json open -e config.json

Un fichier s'ouvre. Change seulement ces 4 lignes (garde les guillemets " " et la virgule à la fin) :

  • store_url → le nom de ta boutique suivi de .myshopify.com
  • client_id → celui de l'étape 5
  • client_secret → celui de l'étape 5 (remplace tout, y compris le début)
  • collection_id → voir encadré ci-dessous
📂 Trouver le collection_id : dans Shopify, va dans Produits → Collections → ouvre la collection où tu ranges tes prods (ou crée-en une). L'adresse se termine par un numéro. Écris : gid://shopify/Collection/LENUMERO

Enregistre avec Cmd + S.

12

Connecte-toi à Shopify (une seule fois)

Ferme Chrome (Cmd + Q). Puis colle cette ligne dans le Terminal :

"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --user-data-dir="$PWD/chrome_profile" "https://admin.shopify.com"

Une fenêtre Chrome toute neuve s'ouvre. Connecte-toi à Shopify comme d'habitude, jusqu'à voir ton tableau de bord.

Dans cette fenêtre, tape dans la barre d'adresse : chrome://settings/onStartup et choisis "Reprendre là où vous en étiez".

Ferme Chrome avec Cmd + Q.

🎉 C'est fini ! L'installation est terminée. Passe maintenant au document "2 - Lancer le bot" pour envoyer ta première prod.
Un souci en cours de route ? Note le message exact affiché dans le Terminal et montre-le à la personne qui t'aide.
Ne partage jamais ton fichier config.json avec personne.
