Lancer le bot

Pour envoyer une nouvelle prod sur Shopify

👋 Ce document sert à chaque fois que tu veux mettre une prod en ligne.

Avant de commencer, prépare tes fichiers : la cover (image), le MP3, et si tu en as, le WAV et les stems (fichier .zip ou .rar).

⏱️ Ça prend 3 à 5 minutes.
1

Ferme Chrome

Appuie sur Cmd + Q. Si Chrome reste ouvert, le bot ne peut pas fonctionner.

2

Ouvre le Terminal

Appuie sur Cmd + Espace, tape Terminal, puis Entrée.

3

Va dans le dossier du bot

Tape cd puis une espace (sans appuyer sur Entrée). Glisse le dossier scripts depuis le Finder dans la fenêtre du Terminal. Appuie sur Entrée.

✅ Tu sais que c'est bon quand la ligne se termine par scripts %
4

Lance le bot

Colle cette ligne, puis Entrée :

bash run_single_upload.sh
5

Choisis tes fichiers

Des fenêtres s'ouvrent l'une après l'autre. Clique sur chaque fichier demandé, dans cet ordre :

  1. La cover
  2. Le MP3
  3. Le WAV — clique Annuler si tu n'en as pas
  4. Les stems — clique Annuler si tu n'en as pas

Puis tape le nom de la prod, le BPM, et les tags séparés par des virgules.

👀 Tu ne vois pas les fenêtres ? Regarde derrière le Terminal, ou dans le Dock en bas de l'écran.
6

Attends

Le bot travaille tout seul. Ne ferme ni le Terminal, ni Chrome. Ça prend quelques minutes.

🔑 macOS te demande un mot de passe ? C'est normal, entre-le et clique sur "Toujours autoriser".
7

C'est fini !

Tu dois voir apparaître dans le Terminal :

✅ Beat 1: SUCCESS - (le nom de ta prod) Script terminé — FIN
8

Vérifie dans Shopify

Ouvre ta boutique, va dans Produits, et regarde ta prod : le titre, les tags, le BPM, la cover, les licences.

⚠️ Attention : la prod est mise en ligne tout de suite, elle est visible par tes clients. Si c'est juste un test, supprime-la après.
🎉 Bravo ! Ta prod est en ligne. Refais ces 8 étapes à chaque nouvelle prod.
🆘

Si Shopify redemande de se connecter

Ça arrive parfois. Voici quoi faire :

  1. Dans le Terminal, appuie sur Ctrl + C
  2. Ferme Chrome (Cmd + Q)
  3. Colle cette ligne dans le Terminal :
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --user-data-dir="$PWD/chrome_profile" "https://admin.shopify.com"
  1. Connecte-toi à Shopify dans cette fenêtre
  2. Ferme Chrome (Cmd + Q)
  3. Relance le bot depuis l'étape 4
💡

Petits soucis fréquents

Erreur "no such file"Tu n'es pas dans le bon dossier. Refais l'étape 3.
Le bot redemande de se connecterVa voir juste au-dessus, section "Si Shopify redemande de se connecter".
Une prod refuse de se créerUne prod avec le même nom existe peut-être déjà sur Shopify.
Autre erreur en rougeCopie le texte affiché et montre-le à la personne qui t'a aidé à installer.
Ne partage jamais ton fichier config.json ni le dossier chrome_profile avec personne.
